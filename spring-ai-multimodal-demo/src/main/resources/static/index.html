Spring AI · Portable Model API

Multimodal Bench

Three of Spring AI's model abstractions, exercised through a single page. The framework ships no Google adapter for any of these, so each one is a hand-written implementation of a Spring AI interface, backed by Gemini. Set GEMINI_API_KEY in .env and run.

01 · Text → Image

Generate

impl of org.springframework.ai.image.ImageModel

02 · Audio → Text

Transcribe

impl of org.springframework.ai…TranscriptionModel

Drop an audio file or browse
wav · mp3 · m4a · ogg · webm
03 · Text → Speech

Speak

mirror of org.springframework.ai…TextToSpeechModel

What's happening: every request hits a controller that depends only on a Spring AI interface — the Gemini provider is injected, never referenced by callers. Swap in OpenAiImageModel or OpenAiAudioTranscriptionModel and the controllers wouldn't change a line.
Note: Claude / Anthropic models can't power any of these — they're text + vision only.
